# Legal Ease – AI-Powered Legal Document Generator

## Project Description
Legal Ease is a web-based project that helps users generate structured legal document templates by entering basic information.

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- ReportLab

## Features
1. User-friendly interface
2. Multiple legal document types
3. Automatic document generation
4. Generated document preview
5. PDF download option

## How to Run

### Step 1
Install Python.

### Step 2
Open the project folder in Terminal/Command Prompt.

### Step 3
Install required packages:

    pip install -r requirements.txt

### Step 4
Run the application:

    python app.py

### Step 5
Open the browser and visit:

    http://127.0.0.1:5000

## Note
This project is intended for educational/demo purposes. Generated documents should be reviewed by a qualified legal professional when legally required.
